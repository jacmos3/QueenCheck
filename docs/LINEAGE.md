# Repository lineage

QueenCheck begins from the frozen `ChessGameSolidity` history so authorship, license, audit work, and the architectural evolution remain inspectable. The last historical milestone is tag `protocol-lab-v1.0.0` at commit `8a3c20f`.

The QueenCheck reset removes the former economic protocol from the current tree. Old commits remain reachable as history; that fact is intentional evidence, not an assertion that the old design is current, compliant, audited, or supported. Current release claims apply only to the exact QueenCheck commit being built or deployed.

The repository is independent rather than a GitHub fork-network child. This organizational choice does not erase provenance or change the MIT license obligations.
